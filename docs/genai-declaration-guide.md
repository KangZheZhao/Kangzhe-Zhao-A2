# GenAI use declaration guide

The Assessment Brief (pages 6–7) permits GenAI for brainstorming, grammar checks, editing wording or tone, formatting, and layout templates. It does not permit GenAI to create report text or code for a student to copy into the submission.

Use the brief's **used GenAI** statement only when it describes what actually happened. Replace the two bracketed fields with the tool name and specific purposes:

> I acknowledge that I have used GenAI tools to complete this assessment. I used [GenAI tool(s)] to [specific purpose(s) of using GenAI] within the parameters outlined in the Assessment Brief and by the Unit Assessor.

For example, if this is the full extent of the use:

> I acknowledge that I have used GenAI tools to complete this assessment. I used ChatGPT to brainstorm event ideas and check grammar within the parameters outlined in the Assessment Brief and by the Unit Assessor.

If no GenAI tool was knowingly used, the brief gives this statement:

> I acknowledge that I have not knowingly used GenAI to complete this assessment.

The statement in the project report records this project's actual Codex use. It cannot be replaced by the limited-use example above, because Codex also drafted code and report text. A declaration does not make prohibited use compliant.
