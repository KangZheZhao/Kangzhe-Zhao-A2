# Demo video notes

Keep the video under 15 minutes and explain the project in your own voice. One possible order:

1. Show the home page and say what the site is for.
2. Open the SQL file and point out the three tables, keys and sample events.
3. Show the API routes and try a filtered event request.
4. Follow one `fetch` call from a page script to the JSON result on screen.
5. Search with a couple of filters, clear them, then open an event. Click Register to show the demo alert.
6. Briefly show the About page and the Git commits.

Watch the recording once before sharing it. Check that the text and audio are clear and that the OneDrive link opens for the marker.
