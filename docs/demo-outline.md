# Personal demonstration outline

The assessment asks for a video of no more than 15 minutes that explains the student's own understanding and demonstrates the working site. Record the explanation in the student's own voice and upload the finished file to SCU OneDrive.

| Approximate time | Show and explain |
| --- | --- |
| 0:00-1:00 | Introduce the Sydney charity-event use case and the three public pages. |
| 1:00-3:30 | Open the SQL file. Explain the three tables, the primary and foreign keys, eight upcoming sample events, and past/suspended records. |
| 3:30-6:30 | Show `event_db.js` and the three Express GET routes. Use a browser or Postman to request categories, the event list and a filtered search. |
| 6:30-9:00 | Trace one browser `fetch` call through the API response to DOM rendering in a page script. Point out loading, empty and error handling. |
| 9:00-13:30 | Demonstrate the home page, combine two or three search filters, clear them, open an event, show ticket and fundraising progress, and click Register. |
| 13:30-14:30 | Show the private GitHub progress commits and briefly explain the validation performed. |

Before sharing the link, replay the recording to confirm that the code, spoken explanation, browser text and audio are clear, and that the OneDrive permission lets the marker view it.
